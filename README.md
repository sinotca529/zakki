# zakki

`zakki` は Markdown を HTML に変換する静的サイトジェネレーターです。<br>
変換には [`pulldown-cmark`](https://docs.rs/pulldown-cmark/latest/pulldown_cmark/) を利用しています。<br>
CommonMark と GitHub Flavored Markdown に加えて、脚注・数式・注記・ウィキリンクなどの拡張を有効にしています。

## 主な機能

- サイト生成時の数式描画
- 下書き機能
- ページの暗号化
- サイト内検索
- コードハイライト
- コードブロックへのキャプション付け
- `file://` プロトコルでの動作

## 使い方

- `zakki init` コマンドでひな形を作成します。
- `zakki build` コマンドでサイトを生成します (下書きは変換されません)。
- `zakki build -d` コマンドでサイトを生成します (下書きも変換されます)。

ヘルプは `zakki --help` で確認できます。

### 設定ファイル

設定は `zakki.toml` に記述します。

```toml
site_name = "(必須) サイト名を指定します。"
password  = "(任意) 暗号化用のパスワードを指定します。"
footer    = "(任意) フッターの内容を HTML で指定します。"
search_fp = "(任意) サイト内検索の偽陽性率を指定します。デフォルトは 0.0001 (0.01%) です。"
js_list   = ["(任意) 追加する javascript ファイルを指定します。"]
css_list  = ["(任意) 追加する css ファイルを指定します。"]

# (任意) コードブロックに使うフォントを指定します。
[code_font]
path    = "(必須) フォントファイルのパスを指定します。"
name    = "(任意) 1 ファイルに複数のフォントが入っている場合 (.ttc) に、どれを使うかをフォント名で指定します。"
license = "(任意) 出力に添えるライセンス文書のパスを指定します。"
```

Google Analytics などの javascript を追加する場合は、`js_list` に追加してください。

### ディレクトリ構造

Zakki のディレクトリ構造は次のようになっています。

```txt
.
├── src
│  ├── public/       # 公開する記事を配置します
│  ├── private/      # パスワード付きで公開する記事を配置します
│  ├── draft/        # 下書きを配置します (zakki build -d でのみビルドされます)
│  ├── gtag.js
│  └── favicon.ico
├── build/
└── zakki.toml
```

### サブページ

サブページはトップのページ一覧に表示されないページです。
`public`, `private`, `draft` ディレクトリ直下になく、かつ、名前が `index.md` ではないファイルがサブページとして扱われます。
サブページは検索の対象には含まれます。

```txt
.
└── src/public/
   ├── foo.md        # ページ一覧に表示される
   └── bar/
       ├── index.md  # ページ一覧に表示される
       └── sub.md    # ページ一覧に表示されない
```

### ページのメタデータ

ページのメタデータは yaml ヘッダに記述します。

```md
---
title:  見出し       # 記事のタイトル (必須)
create: 2024-05-13   # 記事の作成日 (必須)
update: 2024-08-15   # 記事の最終更新日 (必須)
tags:   [数学, tips] # 記事に付けるタグ
password: test       # 暗号化のパスワード (指定がない場合は zakki.toml の値が使用されます)
---

こんにちは
```

`password` は記事が `private/` 配下にない場合は無視されます。

### ページの本文

ページの本文は `##` (h2) から始める必要があります。 \
これは、ページのメタデータとして設定した `title` が `#` (h1) に変換されるためです。

さらに、ヘッダのレベルは 1 つ順番に下げていく必要があります。 \
例えば、 `##` の直後に `####` が来てはいけません。

### コードのハイライト

指定した区切り文字で囲まれた範囲にスタイルを適用できます。

````md
---
create: 2024-05-13
update: 2024-08-15
tags: [misc]
highlights:
  [
    { delim: ["r@", "@"], style: font-weight:bold;color:red },
    { delim: ["g@", "@"], style: font-weight:bold;color:green },
    { delim: ["b@", "@"], style: font-weight:bold;color:blue },
  ]
---

## ハイライト

```
r@ここは赤@g@ここは緑@b@ここは青@
```
````

### コードブロックのキャプション

言語指定に `:キャプション` を付けると、コードブロックにタイトルを表示できます。

````md
```rust:main.rs
fn main() {
    println!("Hello, world!");
}
```
````

### コードブロックのフォント

コードブロックの中で図を書くと、日本語が全角 1 文字ぶんしか進まないため、半角 2 文字ぶんを前提に描いた罫線が揃いません。<br>
Latin の等幅フォントの半角は 0.6 em 前後で、全角の半分になりません。日本語を持つフォントに揃えないと、比が 1 対 2 になりません。

`zakki.toml` の `code_font` に日本語の等幅フォントを指定すると、記事で実際に使われた文字だけを抜き出したフォントを生成し、サイトと一緒に配ります。<br>
集めるのは、コードブロック、インラインコード、コードブロックのキャプションです。等幅で描く場所はこれで全部です。

```toml
[code_font]
path    = "~/.local/share/fonts/HackGenConsole-Regular.ttf"
license = "~/.local/share/fonts/HackGen-LICENSE.txt"
```

想定しているのは、半角を 0.5 em、全角を 1.0 em で設計した日本語の等幅フォントです。<br>
罫線素片や矢印は、半角で描く変種を選んでください。HackGen Console や PlemolJP Console のように、名前に `Console` の付く変種が該当します。

次の制限があります。

- TrueType アウトライン (`glyf`) を持つフォントに限ります。CFF アウトラインのフォント (多くの `.otf`) は縮まないため、指定するとビルドが止まります
- フォントが `OS/2` の `fsType` で埋め込みまたはサブセットを禁じている場合、ビルドが止まります
- 記事で等幅に使われた文字をフォントが 1 つも持っていない場合も、ビルドが止まります
- `.ttc` のように 1 つのファイルへ複数のフォントが入っている場合、`name` で 1 つ選びます。指定がないときと、名前が合わないときは、入っているフォント名を挙げて止まります
- 生成したフォントには元フォントの名前を残しません。改変したものに元の名前を使わせない条件 (SIL Open Font License でいう Reserved Font Name) を踏まないためです
- 著作権表示とライセンスはフォントの中に残しますが、`license` にパスを書くと、その文書も `build/font/` にコピーします

指定がなければフォントを配りません。コードは閲覧する人の環境の等幅フォントで描かれます。

### 記事へのリンク

`[[path]]` 形式のウィキリンクは、リンク先の記事のタイトルを表示するリンクになります。<br>
リンク文字列を空にした場合も同じです。リンク先の `.md` は `.html` に変換されます。

```md
[[bar/index.md]]  →  参照先の記事へのリンク
[](bar/index.md)  →  同上
```

### 数式

`$...$` でインライン、`$$...$$` でディスプレイの数式を書けます。<br>
サイト生成時に KaTeX で HTML に変換されるため、閲覧時に javascript は不要です。

```md
インライン: $e = mc^2$

ディスプレイ: $$\int_0^1 x^2 dx = \frac{1}{3}$$
```

### 注記

GitHub と同じ記法の注記を書けます。

```md
> [!NOTE]
> 補足です。
```

## 暗号化のしくみ

[staticrypt](https://github.com/robinmoisson/staticrypt) と同様の仕組みでページを暗号化しています。<br>
ページの生成時に、内容は aes256cbc で暗号化されます。<br>
ページの表示時に、パスワードが入力されると javascript で復号します。<br>

## サイト内検索

[bloom filter](https://ja.wikipedia.org/wiki/%E3%83%96%E3%83%AB%E3%83%BC%E3%83%A0%E3%83%95%E3%82%A3%E3%83%AB%E3%82%BF) による軽量な全文検索を実現しています。<br>
Bloom filter は確率的な手法であり、正確さとメタデータの大きさの間にトレードオフがあります。<br>
`zakki.toml` の `search_fp` を使うと、偽陽性率の目安を指定できます。<br>
小さい数値を指定するほど、検索が正確になり、メタデータのサイズが大きくなります。
