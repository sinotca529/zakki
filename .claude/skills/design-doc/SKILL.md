# PR 本文と設計の文書

生成した文章は、網羅する方向に寄ります。重要度を選ばず、結論を後ろに置き、
定型の見出しを埋め、自明な案にも両論を並べます。読み手が選別を肩代わりすることになるので、
次の形に絞ります。

- 結論を先頭に書く。採用した案とその理由を 3 行以内にまとめ、詳細はその後に続ける
- 採用しなかった案は、案と却下理由の 2 列の表にする。毎回メリットとデメリットを書き下さない
- やらないことを書く。スコープの外の一般論や、将来の拡張の可能性は並べない
- 背景、目的、用語定義のような定型の見出しは、読み手がそれを知らないと判断できないときだけ書く
- 書き終えたら、節ごとに「これがなくてもレビュアーは判断できるか」を確かめる。できるなら消す

文体は AGENTS.md の文体の節に従います。CI が確認することを書かない決まりは、
AGENTS.md の検証の節にあります。
